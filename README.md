## How this repository works

- Plain HTML pages and one stylesheet (`style.css`). No build step, no scripts, no external requests.
- GitHub Pages serves the `main` branch root. Edit a page, commit and push; the public site updates within a few minutes.
- After every update, open the live site in a private window to confirm it loads without signing in.

## Data policy

This repository is public. It contains no patient data, sample identifiers, genomic coordinates or internal server paths, and none should ever be added here.
