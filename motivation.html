Motivation

The review problem

Somatic variants in cardiac tissue are an active research question, but cardiac WES is not a setting where a single caller output can be accepted as is. Different somatic callers can disagree, candidate lists may include technical artifacts, and low allele fractions make true events hard to separate from noise. In practice an expert must decide which candidates deserve attention, and that decision is limited by time and by how clearly the evidence is presented.

Why separate technical ranking from biology

If biological plausibility (for example, a well-known cardiac gene) is mixed into candidate selection, the shortlist can look convincing while hiding weak technical support, and reviewers can no longer tell why a candidate was selected. This project therefore ranks candidates only on technical criteria, then presents biological evidence downstream, next to the ranking but never inside it.

Why a learned, multi-criteria score

No single technical signal is sufficient. Read support, allele fraction, caller concordance and quality indicators each capture part of the picture. A learned score can combine them, but only if it is compared honestly against simple alternatives on the same data. Whether it helps is treated as a question to test, not an assumption.
